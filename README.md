# Study Player

A lightweight desktop video player built with **React** and **Vite**. It offers a Windows‑style file explorer and VLC‑style controls, letting you stream locally stored videos securely without any uploads.

## Description

Study Player emulates a desktop file manager, letting you navigate folders with breadcrumbs, expand/collapse directory trees, and sort entries. When a video is selected, it is streamed via a temporary object URL generated by the browser, ensuring the file never leaves your machine. Playback controls—seek bar, volume slider, fullscreen, and speed adjustment—are styled after classic VLC interfaces.

---

## Features

- **File Explorer UI** – Windows‑like navigation with breadcrumbs, collapsible directories, and sortable entries.  
- **VLC‑style Player** – Custom controls: seek bar, volume slider, fullscreen, and playback speed.  
- **Secure Local Playback** – Streams through in‑browser object URLs; no files are uploaded or stored remotely.  
- **Minimal Dependencies** – React 18, Vite, Lucide React icons, and date‑fns for date formatting.

## Getting Started

1. **Clone the repository**  
   ```bash
   git clone https://github.com/shubhyagami/Study-player.git
   cd Study-player
   ```

2. **Install dependencies**  
   ```bash
   npm ci
   ```

3. **Run the development server**  
   ```bash
   npm run dev
   ```

4. **Open the app**  
   The dev server typically runs at `http://localhost:5173`.  
   - Click **Open Course Folder**, select the directory containing your videos, grant permission, and double‑click a video to start playback.

## Deployment to Vercel

1. Push changes to a GitHub repository.  
2. Sign in to [Vercel](https://vercel.com/) and click **Add New Project**.  
3. Import the GitHub repository.  
4. Vercel auto‑detects Vite; keep the default build command (`npm run build`) and output directory (`dist`).  
5. Click **Deploy**.
