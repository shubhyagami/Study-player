# Study Player

A lightweight local video course player built with **React** and **Vite**.  
It provides a Windows‑like file explorer interface and VLC‑style playback controls, enabling you to stream locally downloaded videos securely without any uploads.

## Description

Study Player mimics a file explorer so you can browse your video folders with breadcrumbs, expand/collapse directories, and sort entries. When you open a video it streams via a temporary object URL generated by the browser, ensuring the files never leave your machine. Playback controls include a seek bar, volume slider, and fullscreen support, styled after classic VLC interfaces.

## Features

- **File Explorer UI** – Windows‑style navigation with breadcrumbs, folder expansion, and sortable entries.  
- **VLC‑style Player** – Custom controls: seek bar, volume slider, fullscreen, and playback speed adjustment.  
- **Secure Local Playback** – Uses in‑browser object URLs; no files are uploaded or stored remotely.  
- **Minimal dependencies** – React 18, Vite, Lucide React icons, and date‑fns for formatting utilities.

## Prerequisites

- **Node.js** ≥ 18  
- A **Chromium‑based** browser (Chrome, Edge, or similar)

## Getting Started

1. **Clone the repository**  
   ```bash
   git clone https://github.com/shubhyagami/Study-player.git
   cd Study-player
   ```

2. **Install dependencies**  
   ```bash
   npm ci
   ```

3. **Start the development server**  
   ```bash
   npm run dev
   ```

4. **Open the app**  
   The dev server typically runs at `http://localhost:5173`.  
   - Click **Open Course Folder**, select the directory that contains your videos, grant permission, and double‑click a video to begin playback.

## Deployment to Vercel

1. Push your changes to a GitHub repository.  
2. Sign in to [Vercel](https://vercel.com/) and click **Add New Project**.  
3. Import the GitHub repository.  
4. Vercel automatically detects Vite; keep the default build command (`npm run build`) and output directory (`dist`).  
5. Click **Deploy**.
